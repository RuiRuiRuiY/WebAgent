# MVP 任务拆解清单

## 1. 第一阶段：基础闭环

目标：完成一个可用的网页聊天代理。

### 前端任务

-  初始化 Next.js 项目
-  集成 assistant-ui
-  实现聊天页面
-  实现消息输入与发送
-  实现消息列表展示

### 后端任务

-  初始化 Python 项目
-  搭建 FastAPI 服务
-  创建 LangGraph 最小图
-  实现基础消息回复
-  提供 `/chat` 接口

### 联调任务

-  前后端打通
-  本地启动验证
-  处理 CORS
-  验证消息闭环

------

## 2. 第二阶段：Agent 能力

目标：让 Agent 从“聊天机器人”升级为“任务执行者”。

### 后端任务

-  引入 DeepAgents
-  设计规划节点
-  设计工具节点
-  支持多步执行
-  支持中间状态更新

### 前端任务

-  显示加载/思考状态
-  展示工具调用状态
-  支持流式结果渲染

### 联调任务

-  工具调用闭环
-  多步任务验证
-  错误重试验证

------

## 3. 第三阶段：会话与持久化

目标：支持可恢复的对话体验。

### 后端任务

-  增加线程ID
-  保存消息历史
-  保存工具执行记录
-  支持恢复会话

### 前端任务

-  新建会话
-  会话切换
-  历史会话列表
-  页面刷新恢复上下文

------

## 4. 第四阶段：产品化

目标：让项目适合长期使用和部署。

### 后端任务

-  增加基础鉴权
-  增加配置管理
-  增加日志与监控
-  优化部署脚本

### 前端任务

-  设置页
-  模型与工具配置页
-  UI 细节优化
-  移动端适配

------

## 5. 推荐执行顺序

1. 先完成 **聊天闭环**
2. 再次接入**LangGraph + DeepAgents**
3. 再做 **会话持久化**
4. 最后做 **部署与产品化**
